## Getting Started

1. Clone the repo and move into the project folder:
   ```bash
   cd ai-advisor
   ```

2. Get a Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey).

3. Create a `.env.local` file in the project root and add your key:
   ```
   GEMINI_API_KEY="<PUT API KEY HERE>"
   ```

4. Install dependencies:
   ```bash
   npm i
   ```

5. Run the app:
   ```bash
   npm run dev
   ```

Done — enjoy! 🎉
