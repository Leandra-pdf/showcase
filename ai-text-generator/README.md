## Getting Started

1. Move into the project folder:
   ```bash
   cd ai-text-generator
   ```

2. Get a Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey).

3. Create a `config.js` file in the project root and add your key:
   ```js
   const API_KEY ="<PUT API KEY HERE>";
   ```

4. Use `index.html` to run the website by double-clicking it in your file manager or use VSCode's integrated browser.

Done — enjoy! 🎉
